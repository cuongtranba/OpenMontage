## Purpose

Owns the project workspace lifecycle and stage state machine: init_project() creates the canonical projects/<id>/ layout + project.json marker; checkpoint read/write with stage validation; get_next_stage() resume logic; gate enforcement — a stage with human_approval_default: true cannot be written completed without human_approved=True (GATE VIOLATION raised otherwise); superseded checkpoints archive to history/. pipeline_loader parses and validates pipeline_defs/ manifests. Not responsible for deciding when to pause — the checkpoint-protocol skill instructs the agent; this component makes violations impossible to persist.
